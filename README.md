# ORRERY · Planetary Synthesizer

A browser synthesizer that turns the real motions of the solar system — orbits, spins and moons, from JPL / IAU data — into sound.

**Play it:** https://analogmission.github.io/Orrery/ · **Quick start:** [quick-start.html](quick-start.html)

Single HTML file, no install. Best in Chrome or Edge with headphones. Press START.

Version v0.300 — first release candidate. See [docs/CHANGELOG-v0_300.md](docs/CHANGELOG-v0_300.md) and [docs/ROADMAP-v0_300.md](docs/ROADMAP-v0_300.md).
